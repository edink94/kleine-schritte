KLEINE SCHRITTE – PWA / iPAD

Diese Version ist als installierbare Web-App vorbereitet.

Wichtig: Für „Zum Home-Bildschirm“ und Offline-Caching muss die App über HTTPS auf einer Website liegen. Eine lokale HTML-Datei in der Dateien-App reicht auf dem iPad nicht.

Nach dem Hochladen:
1. Webadresse in Safari öffnen.
2. Teilen-Symbol antippen.
3. „Zum Home-Bildschirm“ wählen.
4. „Hinzufügen“ antippen.
5. Danach startet Kleine Schritte über ein eigenes Icon und nahezu im Vollbild.

Enthalten:
- index.html
- manifest.webmanifest
- sw.js
- App-Icons für iPhone/iPad
- Offline-Cache
